# Replay: what today's checks would have caught (full table)
Two finished competitions' own records (submissions with CV and public score, dates as recorded; redacted inputs in `<comp>/`) replayed day by day through today's `kit/watcher.sh` (clock shifted to each day, stub Kaggle CLI). Point in time: each day sees only what was on record that day; values learned later (the RSNA 10-16 rescoring, the first gold cut, the first LB-noise measure) enter on their own date from `<comp>/known.csv`. They show what would have been flagged, not what would have been won. Not in the table: 8 RSNA rows also raise `csvbad`, because the record names no control for them; today's log refuses such rows.
